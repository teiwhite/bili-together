# 同屏心动 · B站双人观影网站

不下载视频，粘贴 Bilibili 视频链接，就能创建一个双人私密房间，邀请对方加入、聊天、切换视频，并利用共享时间和五秒倒计时尽可能同步观影。

> **重要限制**：B站官方外链播放器虽然支持 `bvid`、`p`、`t` 参数，但官方公开文档并没有通用的播放、暂停、任意跳转 JavaScript 控制接口。此项目不会假装外部按钮能直接控制 iframe：**共享计时与聊天是真实时同步**；实际视频播放和暂停须各自在 B站播放器中操作；跳转时间会让双方播放器带 `t` 参数重新加载，可能需要重新点播放。也不能保证会员、地区限制、版权限制的视频能外链播放。

## 1. 一分钟启动（Windows 10/11 / macOS / Linux）

1. 安装 [Node.js](https://nodejs.org/) 20 或更新版本，建议 LTS。
2. 解压 `bili-together.zip`。
3. 在解压出的 `bili-together` 文件夹打开终端。
4. Windows 用户也可直接双击 `start-windows.bat` 来启动并打开网页。或在终端运行：

   ```bash
   node server.js
   ```

5. 浏览器打开：**http://localhost:3000**。

也可以运行 `npm start`，**不需要 `npm install`**，因为后端只用 Node.js 内置模块，前端也不依赖第三方库。

如果你想改变端口：

- Windows PowerShell: `$env:PORT=4000; node server.js`
- macOS / Linux: `PORT=4000 node server.js`

停止服务器：在终端按 `Ctrl+C`。

## 2. 两人使用流程

1. 把 B站视频页完整地址（示例：`https://www.bilibili.com/video/BV1Lvu3zhEpr/`）粘贴到首页，输入昵称，点击 **创建我们的观影室**。
2. 点击右上角 **复制邀请链接**，发送给另一人；对方填写昵称进入房间。
3. 两人都点击 **我准备好了**，网站会自动开始 **5 秒倒计时**。到 0 时，双方**手动点击 B站播放器内的播放键**。也可由一人点击 **5 秒后一起播放**。
4. 一方点击 **暂停共享计时**，另一方会看到提示，并自行暂停播放器。
5. 需要跳转时，输入 `01:25` 或 `85` 秒，点击 **跳转到此时间**，会同时刷新两个人的 B站播放器，并设置初始时间；请各自点播放。
6. 可点击 **对齐播放器进度** 以当前共享时间重新加载播放器；右侧可以实时聊天。
7. 粘贴另一个 B站视频链接到下方的 **换一部视频**，两端立即加载新视频。

支持 `b23.tv` 短链接，但服务器必须能访问 B站才能解析；若解析失败，复制完整的 `bilibili.com/video/BV...` 网址即可。

## 3. 让异地的女朋友也能访问

`localhost` 只能在你自己的电脑使用；需要把 Node 服务部署到有公网 HTTPS 域名的平台。推荐采用 **Render Web Service、Railway 或其他支持长期运行 Node HTTP 服务及 SSE 的托管平台**：

1. 将解压后的文件上传至自己的 GitHub 仓库。
2. 在托管平台创建新的 **Node.js Web Service**，连接该仓库。
3. Start command 填：`npm start`（或 `node server.js`）。Build command 可以留空（平台要求时填写 `echo ready`）。
4. 平台自动提供 `PORT` 环境变量，本项目会读取这个变量并监听 `0.0.0.0`。
5. 部署成功后打开分配的 HTTPS 网址，创建房间、分享邀请链接。

托管平台的免费配额/休眠机制可能变化。**本项目房间和聊天记录暂存服务器内存**，一旦服务重启、休眠后重新启动或部署新版本，房间会丢失；上线长期使用建议添加 Redis/数据库和会话认证。仅用一个服务器实例运行，不要在多个互不共享内存的实例后面做负载均衡。

## 4. 实现方式

- 前端：原生 HTML / CSS / JavaScript，移动端自适应。
- 后端：Node.js 20+ 自带 `http` 模块，无需下载包。
- 实时：浏览器原生 `EventSource`（SSE）接收广播，`fetch` POST 发送消息；自动断线重连。
- 房间：12 字节加密随机数生成的不可猜测房间号，最多 2 位成员。身份凭证随机产生，并保存在浏览器标签页的 `sessionStorage` 中，刷新可重连。
- 视频：B站官方的 `https://player.bilibili.com/player.html?bvid=...` 外链播放器，未抓取、下载或转存任何视频流。
- 同步：服务端是共享播放时钟的权威，广播播放意图、暂停、跳转、视频切换；客户端利用服务端时间估计计时和倒计时。
- 聊天：实时广播；最多存储每房间最近 100 条消息；用户内容使用 `textContent` 插入页面，避免脚本注入。
- 暂时离线用户占用席位 10 分钟后会自动被清理。24 小时无人使用的房间也会清理。

## 5. 本地测试

```bash
npm test
```

测试基于 Node 自带 `node:test`，验证网址解析、房间、容量限制、成员身份、聊天、共享计时、跳转与换视频等。**自动化测试不代表 B站外链视频在你的地区能正常播放**；需要浏览器联网实测该视频。

## 6. 常见问题

**Q：为什么两个人的真实视频不能自动暂停？**  
A：嵌入的 B站 iframe 处于不同域，浏览器同源安全机制阻止网页直接操作其中的播放器。B站官方外链文档未提供保证兼容的播放/暂停控制接口，非官方 `postMessage` 方案不能作为稳定功能承诺。

**Q：为什么点“跳转进度”画面会黑一下？**  
A：这是用官方支持的 `t` 参数重新加载播放器，不是原地 seek，等待加载后再播放即可。

**Q：为什么两人无法在不同网络访问 `localhost:3000`？**  
A：`localhost` 是本机地址。异地使用需公网部署；同一 Wi-Fi 可临时使用电脑的局域网 IP 并放行系统防火墙端口。

**Q：部署后出现房间不存在？**  
A：内存房间随进程重启消失，重新创建房间即可。
